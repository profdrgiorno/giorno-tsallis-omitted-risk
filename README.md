# Omitted risk in fitted return models — replication code

Replication package for

> Giorno, J. (2026). *Omitted risk in fitted return models: displacement, regret, and a robust test for one-sided jumps.* Submitted to the *Journal of Econometrics*.

Author: Joilson Giorno, Graduate Program in Economics, State University of Maringá (UEM), Brazil — jgiorno@uem.br

The manuscript is in `paper/`. Every table in the paper is produced by one script in `code/`; the summaries behind each table are in `results/`.

## Layout

```
code/       all scripts, launchers, DGP_MANIFEST.csv and scenarios.json (flat: scripts import each other)
results/    summary files behind each table (small; raw worker outputs are regenerated by the scripts)
paper/      manuscript (.tex, self-contained, and .pdf)
```

## Requirements

Python 3.10 or later with `numpy`, `scipy` and `pandas` (`pip install -r requirements.txt`). `numba` is optional and speeds up the HMM-6 fits in `b3_var.py` about tenfold. `yfinance` is needed only to download the daily data.

## Running the simulations

All simulation scripts split the work over workers and are resumable: rerunning the same command skips paths already in the output file. Example for the size and power study (Table 5), with 51 workers on two computers:

```
# Linux, workers 0-33
for w in $(seq 0 33); do OPENBLAS_NUM_THREADS=1 nohup python3 -I code/full_srj.py $w 51 full_w$w.csv > full_w$w.log 2>&1 & done
# Windows, workers 34-50
.\code\RUN_FULL_WINDOWS.ps1 -First 34 -Last 50
# when all workers finish, in the folder with the full_w*.csv files
python3 code/summarise_full.py
```

The other studies follow the same pattern with their own launchers. Approximate cost on one core: 32 s per path for `b12_run.py`, which gives about 45 minutes for all 4,000 paths on 51 cores.

## Seeds and exact reproducibility

- The 4,000 HMM-6 paths (8 designs × 500) are regenerated exactly from `DGP_MANIFEST.csv`, with all seeds derived from `SeedSequence(20261028)`. The same manifest is used in the companion repository [`profdrgiorno/Giorno_garch_hmm6`](https://github.com/profdrgiorno/Giorno_garch_hmm6).
- Jump draws: `default_rng([seed, 20261031])`. Skewing signs: `default_rng([seed, 20261103])`.
- Results are identical across machines and operating systems. Check: `python3 -I code/b12_run.py 0 4000 test.csv` reproduces the first rows of `results/competitors/b12_all_replications.csv`.

## Data

Raw market data are **not** included. The daily series (SPY from 29 January 1993, the S&P 500 from 1990, the Ibovespa from 1995) are public and are downloaded from Yahoo Finance by `code/download_daily_long.py`. The minute data (SPY and WIN mini-futures, 2026) come from the author's data vendor and are not redistributed; set `PB_RAW` to the folder that holds them.
